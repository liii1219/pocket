# Pocket — MVP

一个文件 141 行，双击 `index.html` 就能跑。不用装东西，不用起服务器，断网也行。

## 只有一个问题

```
你现在有多少时间？  →  5 分钟 / 10 分钟  →  照着做  →  完成
```

三屏，没了。

## 为什么没有日历

第一版做了导入 `.ics`，做完发现方向错了。

采访里用户说的是**随时能开始**，而"先去导出一个日历文件再导进来"本身就是一次准备工作，正好撞上第 4 条需求（不用做任何准备）。所以日历整块删掉了，只留下用户自己知道的那件事：现在有多少分钟。

## 为什么只有 5 和 10 分钟

第 2 条需求：受访者说工作日五到十分钟才现实，更长的被描述为不现实。放 15 分钟是和自己的数据打架。

## 五条需求，MVP 覆盖了四条

| | 怎么体现 |
|---|---|
| 空闲时间用不起来 | 打开就能用掉，不用规划 |
| 五到十分钟 | 只有这两个选项 |
| 随时能开始 | 无账号、无设置、无日历，点一下就进第一个动作 |
| 不用准备 | 全部是站着做、穿上班的衣服能做的动作 |
| 要知道做得对不对 | ✗ **没有** —— 需要摄像头，在成品里 |

第五条是 MVP 故意不做的，因为它需要 32MB 的模型和构建流程，会毁掉"双击就开"。

## 代码

`index.html` 141 行：HTML 16 / CSS 28 / JS 97。

JS 里只有三样东西：动作数据、`plan(minutes)`（按时间预算挑动作，留 1 分钟缓冲，同样输入永远同样输出）、三屏的渲染。

完整版（摄像头判定动作对不对、51 个测试、2,143 行）在 `../pocket/`。
